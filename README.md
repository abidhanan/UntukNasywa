# Untuk Nasywa Hasna Nabila

Website kecil bertema pink untuk ngajak Nasywa main. Alurnya:

- Pilih `Mau` atau coba kejar tombol `Tidak mau`.
- Pilih tanggal dan jam.
- Isi makanan, minuman, warna, dresscode, ide main, tempat, lagu, dan catatan.
- Lihat halaman konfirmasi dan salin rencana.

## Menjalankan

```bash
npm install
npm run dev
```

URL lokal default:

```text
http://127.0.0.1:5173/
```

## Build

```bash
npm run build
```
